A desktop terminal for running several coding agents at once.

Run five agents in five tabs and one of them is always stuck waiting on you, on a permission prompt or a question you have not seen. pitwall lights up that tab, notifies you, and takes you there with one key.

  • Free and MIT licensed. No account.
  • Linux, macOS and Windows, x86_64 and arm64.
  • Claude Code, Codex, OpenCode, Gemini CLI, Cursor CLI, pi and Oh My Pi.
  • One command to install.

Install

pitwall runs every day on Linux; the macOS and Windows builds are newer. When a release is out, an Update button installs it, and your tabs and config carry over.

Homebrew, on macOS or Linux

brew install quanticstudios/tap/pitwall

Or the install script, on Linux or macOS

curl -fsSL https://raw.githubusercontent.com/quanticstudios/pitwall/main/scripts/get.sh | sh

Scoop, on Windows

scoop bucket add quanticstudios https://github.com/quanticstudios/scoop-bucket
scoop install pitwall

Or the install script, in PowerShell

irm https://raw.githubusercontent.com/quanticstudios/pitwall/main/scripts/get.ps1 | iex

Then run pitwall. The first window lists the agents on your PATH and sets up their status reporting with one button. The install page covers platforms, pinning a version, updates and building from source.

Try it in five minutes

Use a git repo you don't mind agents changing. On macOS the keys below are Cmd+U, Cmd+Shift+Y, Cmd+Shift+N, Cmd+Shift+R and Cmd+T.

  1. Start two or three agents. Run pitwall in the repo and press Install hooks on the welcome card (or in Settings, Agents), so the agents report their state. Ctrl+Shift+T opens a tab; run claude in one, codex in another, and give each a task that runs a command.
  2. Watch the sidebar. Each tab's row reads Working, Input, Approval, Plan, Done or Error, with the branch and the lines changed.
  3. Press Ctrl+Shift+U. When an agent stops to ask, its row lights up and a desktop notification arrives. The key takes you to the agent that started waiting most recently; press it again for the next one.
  4. Allow or Deny. A Claude Code or Codex permission prompt puts Allow and Deny on the row. Click them, or press Ctrl+Shift+Y or Ctrl+Shift+D. To answer from a phone, turn it on in Settings, Phone, press Pair and scan the QR code; the phone has to reach your computer, for example over Tailscale (the phone page).
  5. Ask for a fleet. Tell Claude Code or Codex "split this across three workers". Each worker gets its own worktree and tab, folded into the orchestrator's row as a bar of their states. Click the bar to list them.
  6. Review and comment. Ctrl+Shift+R opens the tab's changes. Click a line number, type a comment and press Enter. The Send comments button types them all into the agent as one prompt.

See every agent at a glance

Every tab's row says what its agent is doing: Working, Input, Approval, Plan, Done or Error. A tab with three agents in split panes lists each on its own line.

The row also shows the branch, the lines changed, and the pull request with its CI and review. Merge it from the tab's menu; once merged, Archive closes the tab and removes its worktree and branch.

Get to the one that needs you

Ctrl+Shift+U jumps to the agent that started waiting most recently, in any session. Its pane gets a ring in the state's color and you get a desktop notification. Press the key again for the next one.

Any command can ask too: npm test && pitwall notify "tests passed".

Answer without switching windows

Allow or Deny a permission prompt from the sidebar or your phone. Ctrl+Shift+Y and Ctrl+Shift+D press the row's buttons, and on Linux the notification has them too.

Pair your phone by QR code and it lists what needs you, takes typed answers and gets push notifications while locked. There is no account and no relay: the phone talks to your computer over your own network.

Run a fleet of workers

Ask Claude Code or Codex to split a job and it starts one worker per task, each in its own worktree, under its own tab. The orchestrator's row gets a bar with a segment per worker in its state's color, and counts of how many need you, failed, are working and are done. The workers start folded into that row, so ten of them take one row; click the bar to open the tree and watch or type into any of them.

The orchestrator waits with pitwall wait --children. It stops at the first worker that asks a question, and Ctrl+Shift+U takes you to it. When a worker's pull request merges, Archive removes its tab, worktree and branch.

pitwall hooks install teaches both agents these commands, so "split this across three workers" is all you have to say.

pitwall worktree new invoice-pdf -- \
  claude "Render invoices as PDFs"
pitwall worktree new webhook-retry -- \
  codex "Retry failed webhooks"
pitwall wait --children \
  --until done --timeout 30m

Fleet mode

Fleet mode sends each worker to a lane by the size of its task, and each lane runs the model you picked for it. A fast, cheap model takes the small fixes and your strongest model takes the whole features. A lane runs one of your presets, which holds the agent, model and effort.

Every brief starts with your worker contract. A worker with no pull request at its lane's timebox gets one nudge, and the orchestrator hears about it at twice the timebox. Checks that keep failing go back to the orchestrator, or restart the task on the big lane. A finished worker reads PR open until its pull request merges.

To set it up, add a preset per model in Settings, Agents, pick one per lane in Settings, Fleet and turn fleet mode on. Then ask your agent to split the work.

pitwall worktree new login-fix \
  --lane small -- \
  "Fix the login redirect"

Review what the agent changed

Ctrl+Shift+R opens the tab's changes. Comment on any line, then send all the comments to the agent as one prompt.

Untracked files are included. Tick off the files you have read; one the agent touches again comes back unticked. Throw away a file's changes with one button.

Run agents side by side without collisions

Give each agent its own git worktree, and pitwall warns you when two of them edit the same file. Start one from any branch or a pull request number.

Each gets its own ports (3010-3019, then 3020-3029), so two dev servers stop fighting over 3000, and can copy .env and run your setup command. Rows turn amber when two branches touch the same files and red when merging would conflict; the hover card says which to merge first.

Find where agents waste time and tokens

Settings, Agent errors lists the failed commands, tool calls and API errors your agents' hooks report, grouped by cause. zsh: command not found: rg thirty-eight times is one row, with its count and about how many tokens it cost. Sort by count or by tokens, over 7 days, 30 days or all time.

Copy report puts the list on the clipboard as Markdown, so you can hand it to an agent and ask it to fix the causes in CLAUDE.md, your shell config or a missing tool.

Settings, Timing shows where your agents' time goes. Each turn splits into the model, tests, builds, CI, other tools and waiting on you, per day and per task from prompt to merge, with the slowest commands. Both pages read logs the daemon keeps with secrets redacted; the timing log holds no prompts or output.

Know what it costs

See how much of your Claude Code and Codex plan limits you have used, and when you will hit 100% at this pace. The sidebar's footer keeps each agent's fullest window in view.

Settings, Usage also adds up what the last 7, 30 or 90 days would cost at API prices, per agent and per day. The agent panel shows each session's tokens and how full its context is, and lists every subagent, Claude Code workflow runs included, with what it was asked.

Line up the next task

New task (Ctrl+Shift+A) starts an agent on a prompt in a tab of its own, or queues it until a running agent finishes.

Pick the project, a fresh worktree or a branch, the agent and its permission mode. Cap how many agents run at once, and the queue starts the next task as one finishes.

Let one agent hand work to another

An agent can open a tab with pitwall new, start Codex or Claude Code in it on a prompt, and wait for the result with pitwall wait. The tab shows up in your sidebar, so you can watch the work and type into it.

Agents can also talk to each other. pitwall send types a message into another agent at its next prompt, with a header saying who sent it and how to reply, so Claude Code and Codex can argue over a plan until they agree.

When the new agent asks permission, wait stops and reports the question, and you answer it in the tab. pitwall never answers for an agent. Hand the agent skill page to your agent and it knows the commands.

# a second opinion from Codex, in a tab you can watch
tab=$(pitwall new -n "review auth" -- \
  codex "review origin/main..HEAD")
pitwall wait "$tab" --until done --timeout 20m

# run the tests in a tab, go on when they pass
tab=$(pitwall new -n tests -- go test ./...)
pitwall wait "$tab" --until exit

# ask Codex in a split to critique the plan
pane=$(pitwall split -- codex)
pitwall send "$pane" -- "Critique plan.md"

Never lose a session

Close the window, reboot or upgrade, and your tabs come back in their folders with the agents resumed where they left off.

Sessions work like tmux, and the switcher (Ctrl+Shift+S) shows every session's agents before you switch. pitwall --host box runs them on another machine over ssh, so they keep going when the laptop closes.

Pin and color the tabs you keep

Pin a tab and it stays open. Closing it from the window asks you to unpin it first, and pitwall kill from a script or another agent is refused.

Give a tab one of eight colors from its menu and its row takes a faint tint, so the billing work and the webhook fix stop looking alike. A soft green mark under the agent's icon shows which Claude Code sessions have /remote-control on, so you know which ones you can pick up from your phone.

Drive it from the keyboard

Ctrl+Shift+P lists every action with its keys. Ctrl+Shift+F searches the scrollback, copy mode (Ctrl+Shift+X) selects with vi keys, and a selection stays on its text while new output scrolls past.

Ctrl+Shift+H moves focus to the sidebar, where the arrow keys walk the tabs and Enter opens one. Search shortcuts by name or by the keys themselves, pick one of four themes and your own fonts, and rebind any key in Settings or config.toml. On macOS the keys sit on Cmd.
